# StManLoaderCLI
Скачивание игр из steam при помощи manifest. 
Чтобы пользоваться данной программой, нужно в неё зайти, авторизоваться в steam, после этого программой можно пользоваться.
При запуске встречает главное меню
1. Войти в аккаунт steam или удалить свои данные
2. Указать папку куда будет скачиваться игры
3. Начать скачивание игры
4. Выбрать кол-во потоков при скачивании
5. Выбрать для какой операционной системы скачивать игру
6. Что делать с папкой скачанных manifest после скачивания игры
7. Починить игру, если повезёт
8. Выйти из приложения

Чтобы скачать игру нужно указать либо путь к папке с manifest и lua, либо указать AppId игры, которую хотите скачать. Обязательно manifest файлы и lua одной игры должны находится в одной папке без всего остального.
Чтобы скачать архив с manifest и lua, в котором будут нужные данные для скачивания, я использую два места: тг бота @SteamCloudBot, с сайта generator.ryuu.lol.
Пример пути "C:\Games"
