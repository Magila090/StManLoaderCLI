# StManLoaderCLI
Скачивание игр из steam при помощи manifest. 
Чтобы пользоваться данной программой, нужно в неё зайти, авторизоваться в steam и закрыть приложение, после этого программой можно пользоваться.
При запуске встречает главное меню
1. Войти в аккаунт steam или удалить свои данные
2. Указать папку куда будет скачиваться игры
3. Начать скачивание игры
4. Выбрать кол-во потоков при скачивании
5. Выбрать для какой операционной системы скачивать игру
6. Выйти из приложения

Чтобы скачать игру нужно получить архив с manifest и lua в котором будут нужные данные для скачивания, я получаю архив от телеграмм бота @SteamCloudBot.
Так же чтобы скачать игру, manifest файлы и lua должны находится в одной папке без всего остального.
Пример пути "C:\Games"
